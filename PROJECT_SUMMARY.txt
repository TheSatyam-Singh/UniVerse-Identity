📊 OAUTH2 FLOW EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. Authorization Request → /api/oauth/authorize
     - User authenticates and consents
     - Receives authorization code

  2. Token Exchange → POST /api/oauth/token
     - Exchange code for tokens
     - Receives: access_token, refresh_token, id_token

  3. Access Protected Resource → GET /api/oauth/userinfo
     - Use access_token in Authorization header
     - Receives user information

  4. Refresh Token → POST /api/oauth/token
     - Use refresh_token to get new access_token
     - Old refresh_token rotated
